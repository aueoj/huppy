앱이 기기 안에 저장하는 것

아래 정보는 사용자 기기에만 저장되고 운영자에게 전달되지 않습니다. 자세를 판정하고 펫을 키우는 데 씁니다.

  • 기억한 바른 자세. 얼굴의 위치·크기·각도를 나타내는 숫자입니다. 카메라가 바뀌면 다시 기억하도록 어떤 카메라로 기억했는지 구분하는 카메라 ID도 함께 저장합니다. 사진은 남기지 않습니다.
  • 경험치와 진화 단계, 메뉴에서 고른 설정
  • 날짜별 기록. 자세 체크 횟수와 그중 바른 자세였던 횟수, 교정한 횟수, 경고를 무시한 횟수, 스트레칭한 횟수와 건너뛴 횟수, 마지막으로 추정한 화면 거리입니다.
  • 처음 쓴 날과 별점을 부탁했는지 여부
  • 진단 기록. 메뉴에서 '진단 기록 남기기'를 켰을 때만 숫자로 남깁니다.

앱이 인터넷에 연결하는 때

앱은 아래 경우에만 GitHub에 연결합니다. 모두 공개된 파일을 받아 오는 요청이고 사용자 정보를 실어 보내지 않습니다. 다만 요청을 받는 GitHub에는 IP 주소와 앱 이름 같은 요청 정보(User-Agent)가 전달될 수 있습니다.

  • 판정 기준과 대사 받기. 앱을 켤 때와 그 뒤 6시간마다 raw.githubusercontent.com에 연결합니다.
  • 새 버전 확인. 하루 한 번 연결합니다. Mac은 raw.githubusercontent.com의 업데이트 목록을 봅니다. Windows는 api.github.com의 최신 릴리스 정보를 봅니다.
  • 새 버전 내려받기. 사용자가 설치를 고르면 github.com에서 받습니다. Mac은 업데이트 창에서 '향후 업데이트 자동 다운로드 및 설치'를 켜면 그 뒤로는 묻지 않고 새 버전을 받아 설치합니다. 이 설정은 처음에 꺼져 있습니다. 다시 끄려면 터미널에서 아래 명령을 실행해 주세요. 
    defaults write com.posturepet.app SUAutomaticallyUpdate -bool false

의견 보내기

메뉴에서 '별점 남기기'나 '버그 신고하기'를 누르면 브라우저에서 Tally 폼이 열립니다. 제출 버튼을 누른 내용만 전달됩니다. 답장을 드리고 문제를 고치는 데 씁니다.

  • 별점 폼: 폼에 적은 내용
  • 버그 폼: 폼에 적은 내용. 이메일과 첨부 파일은 선택 항목입니다.
  • 두 폼 공통: 앱이 숨은 칸으로 채우는 앱 버전, 운영체제 버전, 진화 단계, 폼을 연 곳

이 사이트

  • 방문 수와 다운로드 버튼 클릭 수를 GoatCounter로 셉니다. 쿠키를 쓰지 않습니다. GoatCounter는 IP 주소나 전체 User-Agent를 저장하지 않고 브라우저 종류나 운영체제, 국가처럼 합산된 숫자만 남긴다고 밝히고 있습니다.
  • 최신 버전을 보여 드리려고 페이지를 열 때 api.github.com에서 릴리스 정보를 받습니다.
  • 글꼴은 jsDelivr에서 받고 사이트는 GitHub Pages에서 제공됩니다.

이때 각 업체에는 접속한 IP 주소와 브라우저 정보가 전달됩니다.

보관 기간

  • 기기에 저장된 정보는 사용자가 지울 때까지 기기에만 남습니다. 운영자는 볼 수 없습니다.
  • 의견 폼으로 받은 내용은 답장과 문제 해결에만 쓰고 해결한 뒤 Tally에서 응답을 삭제합니다. 늦어도 6개월 안에 삭제합니다.
  • 사이트 통계는 누구의 방문인지 알 수 없는 합산 숫자로만 남습니다. GoatCounter는 재방문을 구분하려고 IP 주소와 User-Agent 조합을 최대 8시간 메모리에만 두고 저장하지 않습니다.
  • GitHub와 jsDelivr의 접속 기록은 각 업체의 정책을 따릅니다. 운영자는 이 기록을 받지 않습니다.

기기에 남은 정보 지우기

메뉴의 '기억한 방향' 안에 있는 '기억한 자세 모두 지우기'를 누르면 기억한 바른 자세가 지워집니다. 경험치와 설정까지 모두 지우려면 앱을 지운 뒤 남은 파일도 지워 주세요.

Mac

  1. 허피를 종료하고 응용 프로그램 폴더에서 허피를 휴지통으로 옮겨 주세요.

  2. 터미널에서 아래 명령을 실행해 주세요.

    defaults delete com.posturepet.app

    ~/Library/Preferences/com.posturepet.app.plist에 담긴 기억한 자세, 경험치, 설정이 지워집니다.

  3. Finder의 '이동 → 폴더로 이동'에서 아래 폴더를 하나씩 열어 지워 주세요. 없는 폴더는 건너뛰셔도 됩니다.

    ~/Library/Logs/PosturePet
    진단 기록
    ~/Library/Application Support/PosturePet
    예전 버전이 남긴 기록
    ~/Library/Caches/com.posturepet.app
    macOS가 만든 연결 캐시
    ~/Library/HTTPStorages/com.posturepet.app
    macOS가 만든 연결 캐시

Windows

Windows판은 앱을 제거해도 경험치와 설정 파일이 PC에 남습니다. 아래처럼 직접 지워 주세요.

  1. 설정 → 앱에서 허피를 찾아 제거해 주세요.

  2. 파일 탐색기 주소창에 %APPDATA%를 입력해 열고 Huppy 폴더를 지워 주세요. 설정, 경험치, 진단 기록이 모두 이 폴더에 있습니다.

  3. 예전 시험판을 쓰셨다면 같은 곳에 PosturePet 폴더가 남아 있을 수 있습니다. 있으면 함께 지워 주세요.
