천사가 될 수도, 악마가 될 수도 있어요.

잘 지킬수록 애정 표현이 늘고, 경고를 흘려듣거나 스트레칭을 건너뛰면 경험치가 깎여요. 흑화할수록 투정이 심해지고 판정도 예민해지니까 조심하세요!

잠깐 쉬기

잠깐 자리를 비워야 하면 펫을 클릭해 휴식을 취할 수 있어요.

영상은 이 컴퓨터 밖으로 나가지 않아요

자세를 보려면 카메라가 필요해요. 대신 영상은 어디에도 남지 않습니다.

저장 안 함사진도 영상도 저장하지 않아요. 얼굴 위치 같은 숫자만 잠깐 계산하고 버려요.
전송 안 함분석은 이 컴퓨터 안에서 끝나요. Mac은 Apple Vision, Windows는 MediaPipe로 봐요.
몇 초만 켜짐확인할 때만 잠깐 켜요. 카메라 불이 들어오는 그 순간이에요.
계정 없음가입도 로그인도 없어요.

설치

Mac

  1. Huppy-mac.zip을 받아 압축을 풀고, 나온 허피 앱을 응용 프로그램 폴더로 옮겨요.
  2. 처음 열면 "확인할 수 없음" 창이 떠요. 완료를 눌러 닫아요.
  3. 시스템 설정 → 개인정보 보호 및 보안 맨 아래에서 그래도 열기를 누르고 암호 입력.
  4. 다시 열면 화면 아래에 펫이 나와요. 바르게 앉아서 펫을 누르면 시작.

Windows

  1. Huppy-windows-setup.exe를 받아 실행해요.
  2. "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행을 눌러요.
  3. 알아서 설치되고 작업 표시줄 위에 펫이 나와요. 바르게 앉아서 펫을 누르면 시작.
경고 창은 왜 뜨나요?
개인이 무료로 만든 앱이라 Apple·Microsoft 유료 인증이 없어요. 처음 한 번만 하면 되고 새 버전은 펫이 알려줘요.
Windows는 작업 표시줄 오른쪽 아래 펫 아이콘에서 설정과 쉬기를 고를 수 있어요.

오늘 거북목, 몇 번 나왔을까요?

무료예요. 세는 건 펫이 할게요.
